# Contributing

Thank you for helping improve this Roventis Technologies project.

1. Read the README and `ROVENTIS_STANDARDS.md` before making changes.
2. Keep changes focused and explain the user-visible outcome in the pull request.
3. Do not commit secrets, credentials, customer data, or unapproved third-party material.
4. Run the project's documented checks before opening a pull request.
5. For substantial changes, open an issue first so scope and compatibility can be discussed.

Please preserve upstream attribution and follow the license already present in the repository.
