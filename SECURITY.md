# Security

Do not report sensitive vulnerabilities, credentials, personal information, or private system details in a public issue.

For security reports, contact the repository maintainer privately through the GitHub account for [Prajwal-Kevil](https://github.com/Prajwal-Kevil). Include a concise description, affected version or commit, reproduction steps that use only authorized systems, and any suggested mitigation.

Use all tools and research workflows only on systems, accounts, data, and networks you own or are explicitly authorized to assess.
